# Javascript

## Variables
Tenemos dos formas de crear una variable
- `let` (variable mutable)
- `const` (constante)
- evitemos usar esta opcion `var`

## Convencion  **camelCase** 

- totalPrecio
- userName

Tipos de datos primitivos: `number`, `String`, `boolean`, `null`, `undefined`, `bigint`, `symbol`
y estructurados como `objet` y `function`

## Operadores: Aritmeticos, comparacion y logicos
**Aritmeticos** `+`, `-`, `*`, `/`, `%`, `**`
**comparacion** `===`, `!==`, `>`, `>=`, `<`,`<=`
**Logicos** `&&`(AND), `||` (OR), `!` (NOT)

## Condicionales
`if \ else if \ else`
`switch` (valor {case ...})

## Ciclos

- `for` 
- `while`
- `do`\

## Subrutinas (funciones)

- **DECLARACIONES** `funcion noombre(params){...}`
- **EXPRESIONES** `const nombre = function(params) {...}`
- **FLECHA** `const nombre = (params) => {...}` . callbacks
- **PARAMETROS PRO DEFECTO** `function f(a = 0){...}`

## JSON javascript Object Notation

1. Las claves (keys): deben se oblidatoriamente cadenas de texto encerradas en comillas dobles(""). las comillas simples('') estan prohibidas
2. Los valores Booleanos: En py usamos mayusculas (True, Flase). en JSON se escribe estrictamente en minisculas(true, false)
3. La ausencia de valor: en py decemos None, en JSON se usa null
