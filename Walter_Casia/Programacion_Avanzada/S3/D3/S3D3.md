# ¿Qué es `fetch()`?
`fetch()` es una **función nativa de JavaScript** (disponible en navegadores modernos y en Node.js desde la versión 18) que sirve para **hacer solicitudes HTTP** (como `GET`, `POST`, `PUT`, `DELETE`) a un **servidor o API**.

# ¿Qué devuelve `fetch()`?

`fetch()` devuelve una **Promesa** que se **resuelve** con un objeto de tipo **Response**.  
Este objeto representa la **respuesta del servidor**, que contiene:
- código de estado (status)
- encabezados (headers)
- cuerpo (body)

```js
fetch("https://jsonplaceholder.typicode.com/users")
    .then( response => response.json() // convierte la respuesta en json)
    .then(data => console.log(data)) // mostrar los datos
    .catch(error => console.error("Error en la solicitud", error))
```

## Métodos del objeto `Response`

| Método | Descripción | Ejemplo |
|--------|--------------|---------|
| `.json()` | Interpreta el cuerpo como JSON | `const data = await res.json();` |
| `.text()` | Devuelve el cuerpo como texto plano | `const html = await res.text();` |
| `.blob()` | Devuelve datos binarios (imágenes, archivos) | `const img = await res.blob();` |
| `.status` | Devuelve el código de estado HTTP | `res.status === 200` |
| `.ok` | Booleano (true si status está entre 200–299) | `if (res.ok) {...}` |

##  Enviar datos con un post 
```js
async function crearUsuario() {

    const nuevoUsuarios = {
        name: "Diego Orozco",
        email: "diego@orozco.com"
    }

    try {
        const respuesta = await fetch("https://jsonplaceholder.typicode.com/users", {
            method: "POST",
            header: {
                "Content-Type": "application/json"
            },
            body: JSON.stringify(nuevoUsuario)
        });

        const data = await respuesta.json();

        console.log("Usuario creado: ", data)

    }
    catch (error) {
        console.error("Hubo un problema con la creación: ", error.message)
    }
}

crearUsuario()
```

# Uso del archivo `.env` en Nodejs
El archivo **`.env`** (de *environment variables*) se utiliza para **almacenar configuraciones sensibles o cambiantes** fuera del código fuente

## Librería `dotenv`

Para poder usar archivos `.env` en Node.js se instala la librería:

```bash
npm install dotenv
```

Y se carga al inicio del programa principal (`app.js`):

```js
import dotenv from 'dotenv';
dotenv.config();
```




Por ejemplo, si tienes:

```bash
PORT=3000
DB_USER=root
```

Podrás acceder a ellas desde el código con:

```js
console.log(process.env.DB_USER); // "roo






```
