# Modularizacion con express.Router

- `express.Router` es una herramienta nativa de express que funciona como un **mini-servidor independiente**
- Nos permite agrupar rutas que tiene relacion entre si dentro de su propio archivo y luego "conectarlas" al servidor principal.
-  si todas las rutas estan relacionadas con usuarios se usa `/usuarios`. `/usurios:id`, `usuarios/lista`
