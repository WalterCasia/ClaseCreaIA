# **Síncrono vs Asíncrono** en Node.js 
## Callbacks, Promesas y `async/await`


- **Síncrono**: el programa **espera** a que termine cada tarea antes de pasar a la siguiente. Si una tarea tarda 3 segundos, **toda la fila espera**.
- **Asíncrono**: el programa **encarga** tareas que tardan y **sigue con lo demás**. Cuando estén listas, se **notifica** y se ejecuta su callback o promesa pendiente.

## El modelo de ejecución de Node.js

### Pila de llamadas (Call Stack)
Lugar donde “vive” el código que se está ejecutando **ahora**. Solo entra una función a la vez. Si esa función es **lenta y bloqueante**, nadie más avanza.


### APIs de Node
Operaciones como temporizadores, lectura/escritura de archivos, se **delegan** a APIs que trabajan en segundo plano. Al terminar, **programan** una devolución (callback o promesa) para que se ejecute luego.

### Colas: **Callback Queue** y **Microtask/Promise Queue**
- **Callback (Task) Queue**: aquí llegan callbacks de timers, I/O, `setImmediate`, etc.  
- **Microtask/Promise Queue**: aquí entran **reacciones de Promesas** y `queueMicrotask`. Es **más prioritaria**: el Event Loop **la vacía antes** de procesar la cola de callbacks.


### Event Loop (bucle de eventos)
El Event Loop **revisa** si la Pila está vacía; cuando lo está, primero procesa **microtareas** (promesas), luego **callbacks** (timers/I/O), y así sucesivamente.

## Código **síncrono** (bloqueante)
```js
console.log("Inicio sincrónico")

function trabajoPesado(ms) {
    const fin = Date.now() + ms;
    while ( Date.now() < fin ) {}
}

trabajoPesado(5000)

console.log("Despues del trabajo pesado")
console.log("Fin sincrónico")
```

## Código **asíncrono** (no bloqueante)
```js
console.log("Inicio asíncrono")
setTimeout ( () => {
    console.log("Temporizador listo (No bloqueó)")
}, 5000);

console.log("Se puede seguir haciendo otras cosas")
console.log("Fin Asíncrono")
```

## Callbacks: el estilo clásico
**Convención error–primero**: `(err, resultado) => { ... }`
```js
const fs = require("fs");

fs.readFile("./datos.txt", "utf8", (err, contenido) => {
  if (err) {
    console.error("Error leyendo archivo:", err.message);
    return;
  }
  console.log("Contenido:", contenido);
  // Se podría encadenar otro callback aquí → “callback hell”
});
```

## Promesas: el puente entre callbacks y `async/await`
Una **promesa** es un objeto que **representa un valor que estará disponible en el futuro**.  
Puede tener tres estados:

| Estado | Significado |
|---------|-------------|
| Pending | La operación aún no ha terminado |
| Fulfilled | La operación se completó correctamente |
| Rejected | La operación falló |

A una promesa se le “suscriben” reacciones usando:
*	.then(...) para cuando se cumple,
 * .catch(...) para cuando falla,
* 	(opcional) .finally(...) para ejecutar algo al final sin importar el resultado.


Ejemplo básico:
```js
const tarea = new Promise( (resolve, reject ) => {
    let exito  = true
    if (exito)
        resolve("Todo salió bien")
    else:
        reject("Algo falló")
})

tarea.then(mensaje => console.log(mensaje))
     .catch(error => console.log(error))
```

### Crear una promesa desde cero
```js 
function tareaAsincrónica(ms) {
    return new Promise((resolve, reject) => {
        if (ms <== 0) {
            return reject(new Error("Tiempo inválido"))
        }
        setTimeout(() => resolve(`Listo en ${ms} ms`), ms)
    })
}

tareaAsincrónica(5000)
    .then(msg => console.log("OK: ", msg))
    .catch(err => console.error("Falló: ", err.message))
    .finally( () => console.log("Siempre me ejecuto"))

```

## En resumen

| Elemento | Qué hace |
|-----------|-----------|
| `Promise` | Representa una operación asincrónica |
| `resolve()` | Indica que la tarea terminó con éxito |
| `reject()` | Indica que hubo un error |
| `then()` | Se ejecuta si todo salió bien |
| `catch()` | Se ejecuta si algo falló |
| `finally()` | Se ejecuta siempre, pase lo que pase |

### Encadenamiento `then/catch/finally`

```js
tareaAsincrona(500)
  .then(msg => {
    console.log(msg);
    return tareaAsincrona(300); // encadena otra promesa
  })
  .then(msg => console.log(msg))
  .catch(err => console.error("Error en cadena:", err.message))
  .finally(() => console.log("Cadena terminada"));
```


| Concepto | Descripción |
|-----------|-------------|
| **Encadenar promesas** | Permite ejecutar tareas asincrónicas una tras otra, en orden |
| **`return` dentro de `.then()`** | Devuelve una nueva promesa que el siguiente `.then()` espera |
| **`.catch()`** | Captura cualquier error ocurrido en la cadena |
| **`.finally()`** | Se ejecuta siempre, al final del proceso |


### Convertir un callback a Promesa

**Opción A (nativa moderna)**: `fs.promises`  
```js
const fs = require("fs").promises;

async function leerArchivo(ruta) {
  const contenido = await fs.readFile(ruta, "utf8");
  return contenido;
}

leerArchivo("./datos.txt")
  .then(c => console.log("Contenido:", c))
  .catch(e => console.error("Error:", e.message));
```

**Opción B (manual)**: envolver con `new Promise`  
```js
const fsCb = require("fs");

function readFileP(ruta, codificacion = "utf8") {
  return new Promise((resolve, reject) => {
    fsCb.readFile(ruta, codificacion, (err, data) => {
      if (err) reject(err);
      else resolve(data);
    });
  });
}
```


## **async** y **await** en JavaScript

### ¿Qué es `async`?
`async` es una **palabra clave** que se pone **antes de una función** para indicar que esa función **siempre devuelve una Promesa**.

```js
// Ejemplo 1: una función async que devuelve un valor inmediato
async function saludar() {
  return "Hola";
//   Promise.resolve("Hola")
}

const p = saludar();       // p es una Promesa
p.then(msg => console.log(msg)); // "Hola"
```


### ¿Qué es `await`?
`await` **pausa** la ejecución **dentro** de una función `async` **hasta que** la promesa **se resuelva o rechace**.
```js
function tarea(ms) {
  return new Promise((resolve) => {
    setTimeout(() => resolve(`Listo en ${ms} ms`), ms);
  });
}

async function ejecutar() {
  console.log("Inicio");
  const r1 = await tarea(500); // espera ~500 ms
  console.log(r1);             // "Listo en 500 ms"
  const r2 = await tarea(300); // espera ~300 ms
  console.log(r2);             // "Listo en 300 ms"
  console.log("Fin");
}

ejecutar();
```

### Cronología real del tiempo (aproximado)

| Tiempo (ms) | Acción ejecutada |
|--------------|------------------|
| 0            | Se ejecuta `ejecutar()` → imprime `"Inicio"` |
| 0–500        | Espera la primera tarea |
| 500          | Promesa 1 se resuelve → imprime `"Listo en 500 ms"` |
| 500–800      | Espera la segunda tarea (300 ms) |
| 800          | Promesa 2 se resuelve → imprime `"Listo en 300 ms"` |
| 800+         | Imprime `"Fin"` |

**Duración total:** ~800 ms.
