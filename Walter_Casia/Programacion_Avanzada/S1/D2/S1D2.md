## NODE.JS

- node.js es un entorno de ejecucion de JavaScript fuera del navegador , construido sbre v8
- es multiplataforma, open-source y esta orientado a un modelo de evenetos (even loop)
- no es un lenguaje , i un servidor web por si mismo 
- limitaciones, no es idead para tareas CPU intensivas

## Runtime environment

Un runtime es el entorno que provee todas las herramientas para ejecutar un lenguaje, en los navegadores, el entorno incluye objetos como `window` o `document`.En node js, el entorno incluye objetos como global, process, fl(file system), http, etc.

## Event loop y asincronia

Node.js funcionancon un unico hilo de ejecucion(single-thread), pero gracias a su event loop puede manejar multiples tareas concurrentes.
