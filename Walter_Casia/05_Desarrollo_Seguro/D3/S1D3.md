## Cuerpo de HTML (HTML Body)
*  **Dónde es:** Entre etiquetas normales. Ejemplo: `<div> VALOR_AQUÍ </div>` o `<p> VALOR_AQUÍ </p>`.
* **Qué caracteres se escapan:** Los 5 básicos obligatorios (`<`, `>`, `&`, `"`, `'`).

## Atributos de HTML
* **Dónde es:** Dentro de las propiedades de una etiqueta. Ejemplo: `<input type="text" name="usuario" value="VALOR_AQUÍ">`.
* **El peligro:** Si el usuario mete una comilla doble (`"`), puede cerrar el atributo `value`, agregar un espacio y meter un evento malicioso: `" onfocus="alert(1)`.
* **Qué se hace:** Aquí es crítico escapar las comillas (`&quot;` y `&#x27;`) para que el atacante no pueda romper las barreras del atributo.


## Contexto de JavaScript (In-Script Context)

* **Dónde es:** Cuando metes una variable del servidor dentro de un bloque de código en el frontend. Ejemplo:
```html
<script>
   const nombreUsuario = "VALOR_AQUÍ";
</script>

```


* **El peligro:** Si el usuario mete `"; alert(1); //`, rompería tu variable y ejecutaría código en tu propia cara.
* **Qué se hace:** ¡El escape de HTML básico aquí **no sirve**! En este contexto se necesita un escape tipo Unicode o JSON (convertir caracteres a formato `\u0022` o usar `JSON.stringify()`).

```javascript
// Función defensiva de codificación para contexto HTML Body
function escaparHTML(stringInseguro) {
    if (!stringInseguro) return '';
    return stringInseguro.replace(/[&<>"']/g, function(caracter) {
        const mapaEntidades = {
            '&': '&amp;',
            '<': '&lt;',
            '>': '&gt;',
            '"': '&quot;',
            "'": '&#x27;'
        };
        return mapaEntidades[caracter];
    });
}

```

# Anatomía de una Cabecera CSP


```http
Content-Security-Policy: default-src 'self'; script-src 'self' https://apis.google.com; img-src 'self' https://images.unsplash.com; connect-src 'self';
```

* **`default-src 'self'`**: Es la directiva de respaldo (fallback). Si se te olvida definir explícitamente una directiva (como los estilos CSS o las fuentes), el navegador aplicará por defecto lo que diga aquí. En este caso, `'self'` significa: *"Solo permite recursos que vengan exactamente de mi mismo dominio, protocolo y puerto"*.

* **`script-src 'self' https://apis.google.com`**: Controla estrictamente de dónde se pueden descargar y ejecutar archivos JavaScript. Aquí le estás diciendo al navegador que solo ejecute scripts locales (`'self'`) y los que provengan de los servidores oficiales de Google. Si un atacante intenta inyectar un script externo desde `https://sitio-atacante.com/malware.js`, el navegador bloqueará la descarga.

* **`img-src 'self' https://images.unsplash.com`**: Define las fuentes permitidas para las imágenes (`<img>`). El navegador solo renderizará imágenes guardadas en tu servidor o que apunten al dominio de Unsplash. Cualquier otra URL externa será bloqueada, evitando cargas maliciosas de servidores desconocidos.
* 
* **`connect-src 'self'`**: Controla los destinos a los que la aplicación puede enviar o pedir datos usando APIs del navegador como `fetch()`, `Axios` o `WebSockets`.


# El uso de un `nonce`

El servidor lo añade a la cabecera CSP:
```http
Content-Security-Policy: script-src 'self' 'nonce-R4nd0mSt0ng3rKey';

```


El servidor le inyecta ese mismo atributo a los scripts legítimos que tú pusiste en el HTML:
```html
<script nonce="R4nd0mSt0ng3rKey">
    console.log("Este es un script legítimo de la empresa");
</script>
```

## Control de Acceso Basado en Roles (RBAC) para la Escalación Vertical

```javascript
// Middleware de desarrollo seguro que verifica el rol
function verificarAdmin(req, res, next) {
    // El objeto 'req.usuario' fue llenado previamente al validar el Token JWT
    if (req.usuario.role !== 'admin') {
        return res.status(403).json({ error: "Acceso denegado. Se requieren permisos de administrador." });
    }
    next(); // Si es admin, continúa a la ruta
}

// Aplicación segura de la ruta
app.get('/api/admin/usuarios', verificarAdmin, async (req, res) => {
    // Solo se ejecuta si pasó el filtro del middleware
    const usuarios = await db.query('SELECT id, nombre FROM usuarios');
    res.json(usuarios);
});

```
