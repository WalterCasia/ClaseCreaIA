## Inyecciones sql

`SELECT * FROM items`


SQL es un lengujae declarativo e interpretado en tiempo de ejecución

1. EL lexer clasifica los carácteres en:
- palabras reservadas: SELECT, FROM , WHERE, AND
- identificadores: nombres de las tablas o nombres de las columnas 
- operadoresL =, > , LIKE
- literales: cadenas de texto en delimitadores: 'diego', '1234'

2. análisis sintactico (El parser)
- verifica que cumpla las reglas gramaticales del lenguaje SQL
- si la sintaxiss es correcta
- construye una estructura matematica llamada AST ( ABSTRACT SYNNTAX TREE) o árbol de sintaxis abstracta
  - mapa que el motor va a usar para qsaber qué buscar y qué responder 

3. optimizador de consultas 
   calcula el camino más eficiente para recuperar los datos

4. EL motor de ejecución
- transforma el AST optimizado en instrucciones binarios de bajo nivel 



la injección no es un truco de magia, es una vulnerabilidad de confusión de contexto. transforma un literal de datos en una instrucción de control (codigo ejecutable) 

### Ejemplo 1: consulta legítima
```js
const query = `SELECT * FROM users WHERE user = '${username}' AND pass = '${password}'`;
```

si el usuario ingresa un dato limpio en el formulario de login:
* username => 'diego'
* password => 'pass123'

```text
               [Query]
              /       \
       [SELECT]       [WHERE]
          |          /       \
       (users)    [AND]     [AND]
                 /     \       |
          (user='diego')    (pass='pass123')

```

## Carácteries criticos
- `'`: la comilla simple. cierre de delimitador de cadena
- `--` o `#**`. Comentarios
- `OR` / `AND`. Alterar las tablas de verdad
- `;` delimitador de fin de sentencia
